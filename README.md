# Jogja Food: Descriptive Text Game

A minimalist interactive game for practicing English descriptive text. Made for 7th grade students (SMP, Fase D, Kurikulum Merdeka). The theme is favorite food from Jogjakarta: gudeg, bakpia, sate klathak, mie lethek, and yangko.

**Play it here:** https://YOUR-USERNAME.github.io/YOUR-REPO-NAME/

## Learning Goals

- Recognize the structure of a descriptive text (identification and description)
- Learn food adjectives such as sweet, savory, spicy, crispy, soft, and chewy
- Use simple present tense (is, are, has, have, tastes, is made from)

## Game Levels

1. **Word Match**: match adjectives with their meanings
2. **Sentence Order**: arrange sentences into a good paragraph
3. **Fill in the Blank**: complete the text with the right word
4. **Build a Description**: choose the best sentence to finish a short text about gudeg

Each level has 5 questions. Students get instant feedback, a short explanation after each answer, and a final score.

## Features

- One single HTML file, no external libraries
- Mobile-first, works well on phones and laptops
- Minimalist design
- Simple English (A1-A2) with short Indonesian hints
- No login, no data collected

## Run Locally

1. Download `index.html`
2. Open it in any browser

No installation needed.

## Edit the Questions

All questions are stored in one JavaScript object near the top of the `<script>` section in `index.html`. Teachers can change the words, sentences, and answers there without touching the game logic.

## Publish on GitHub Pages

1. Upload `index.html` to your repository (the file must be named exactly `index.html`)
2. Go to **Settings** > **Pages**
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**
4. Choose the `main` branch and the `/ (root)` folder, then tap **Save**
5. Wait 1-2 minutes, then open the link shown at the top of the Pages settings
